# NEXUS HQ v1.0.0 — فایل‌های آماده‌ی نصب

| فایل | برای | حجم | نصب |
|---|---|---|---|
| `NEXUS-HQ-1.0.0-android.apk` | اندروید ۷+ (موبایل و تبلت) | ~۰.۵ MB | دابل‌کلیک روی فایل در گوشی |
| `NEXUS-HQ-1.0.0-windows.exe` | ویندوز ۱۰/۱۱ (۶۴بیتی) | ~۹۵ MB | دابل‌کلیک — بدون نصب (Portable) |

درستی فایل‌ها: `SHA256.txt`

---

## 📱 نصب اندروید

1. فایل APK را به گوشی منتقل کنید (تلگرام، کابل، درایو، ...).
2. روی فایل بزنید. اندروید می‌پرسد «نصب از منابع ناشناس؟» → **اجازه دهید**
   (فقط همان بار اول؛ برنامه هیچ مجوزی جز اینترنت نمی‌خواهد).
3. در اولین اجرا، زبان فارسی و داده‌ی نمونه بالا می‌آید. داده‌ها به‌صورت محلی
   در حافظه‌ی خصوصی برنامه (IndexedDB) ذخیره می‌شوند — کاملاً آفلاین.

- پشتیبان‌گیری: تنظیمات ← خروجی JSON (فایل روی گوشی ذخیره می‌شود)
- حذف برنامه = حذف داده‌ها؛ حتماً بکاپ بگیرید.

## 🪟 اجرای ویندوز

1. روی `NEXUS-HQ-1.0.0-windows.exe` دابل‌کلیک کنید (نیازی به نصب نیست؛ روی فلش هم اجرا می‌شود).
2. یک پنجره‌ی کنسول باز می‌شود و برنامه در مرورگر پیش‌فرض شما بالا می‌آید
   (`http://127.0.0.1:8765`) — کاملاً آفلاین، داده‌ها روی همین کامپیوتر.
3. پنجره‌ی کنسول را باز نگه دارید؛ بستن آن = خروج از برنامه.

> ویندوز ممکن است اولین بار هشدار SmartScreen بدهد (فایل امضای دیجیتال مایکروسافت ندارد) →
> **More info ← Run anyway**. سورس کامل برنامه همین ریپو است.

## این بیلد چگونه ساخته شد؟ (خلاصه فنی)

- **وب‌اپ**: همان کد ریپو — `npm run build` (React + Vite + Tailwind، بیلد وب ~۵۶۰KB).
- **APK**: WebView سبکِ اختصاصی (بدون Capacitor/AndroidX) — کد جاوا به‌صورت smali نوشته و
  با smali-2.0.3 به dex اسمبل شد؛ `AndroidManifest.xml` باینری و `resources.arsc` با
  اسکریپت پایتون ساخته شد؛ امضا: **JAR v1 (SHA256withRSA, RSA-2048)** —
  `targetSdk 29` (نصب روی همه‌ی اندرویدها از ۷ به بالا).
- **EXE**: سرور محلی تک‌فایلی (Bun compile → `bun-windows-x64`) — کل وب‌اپ داخل خود EXE تعبیه شده.
- کلید امضای APK و PEM آن: `build-apk/signing-key.pem` — برای نسخه‌های بعدی همین کلید را
  نگه دارید تا کاربران بتوانند **به‌روزرسانی** کنند (نه حذف/نصب مجدد).

## نسخه‌ی «رسمی‌تر» بعدی

وقتی دسترسی Workflow به گیت‌هاب فعال شد (یا روی کامپیوتر خودتان)، با
`.github/workflows` ریپو (فایل `ci-templates/build-all.yml`) بیلد کامل Capacitor
(پلاگین قفل اثر انگشت، اشتراک‌گذاری فایل) و نصب‌کننده‌ی Setup.exe الکترون هم ساخته می‌شود.
این نسخه‌ی سبک از همان کد و همان داده ساخته شده و کاملاً قابل استفاده است.
