## 🪟 نصب ویندوز — Setup.exe

1. روی `NEXUS-HQ-1.0.0-Setup.exe` دابل‌کلیک کنید.
   - **نیازی به Administrator نیست** — نصب برای کاربر فعلی در `%LOCALAPPDATA%\NEXUS HQ`.
2. نصب‌کننده:
   - برنامه را نصب می‌کند
   - شورتکات **دسکتاپ** و **منوی استارت** با آیکون اختصاصی می‌سازد
   - در **Settings ← Apps ← Installed apps** ثبت می‌شود (قابل حذف با Uninstall)
   - در پایان می‌پرسد: «برنامه اجرا شود؟»
3. اجرای برنامه: کنسول کوچکی باز می‌ماند و برنامه در مرورگر پیش‌فرض بالا می‌آید
   (`http://127.0.0.1:8765`) — کاملاً آفلاین، داده‌ها روی همین کامپیوتر (مرورگر).
4. حذف: **Settings ← Apps ← NEXUS HQ ← Uninstall** — یا `uninstall.cmd` در پوشه‌ی نصب.

> **SmartScreen:** چون فایل امضای دیجیتال مایکروسافت ندارد، ویندوز اولین بار هشدار می‌دهد →
> **More info ← Run anyway**. سورس کامل برنامه همین ریپو است؛ هیچ اتصال اینترنتی‌ای ندارد.
> (چند ثانیه بعد از اجرای Setup صبر کنید — فایل ۹۵ مگابایتی خودش را کپی می‌کند.)

**نکته‌ی پیشرفته (Portable/USB):** اگر کنار Setup.exe یک فایل خالی با نام `.nexus-serve` بسازید،
همان EXE بدون نصب مستقیم برنامه را اجرا می‌کند — مناسب اجرا از فلش.

## 📱 نصب اندروید

1. فایل APK را به گوشی منتقل کنید (تلگرام، کابل، درایو، ...).
2. روی فایل بزنید. اندروید می‌پرسد «نصب از منابع ناشناس؟» → **اجازه دهید**
   (فقط همان بار اول؛ برنامه هیچ مجوزی جز اینترنت نمی‌خواهد).
3. داده‌ها محلی‌اند (IndexedDB) — کاملاً آفلاین. پشتیبان‌گیری: تنظیمات ← خروجی JSON.
   حذف برنامه = حذف داده‌ها؛ حتماً بکاپ بگیرید.

## جزئیات فنی (خلاصه)

- **وب‌اپ**: همان کد ریپو — `npm run build` (React + Vite + Tailwind).
- **Setup.exe**: دو-در-یک با Bun compile (`build-exe/server.ts`) — بار اول = نصب‌کننده
  (کپی + شورتکات‌های PowerShell/WScript + ثبت در رجیستری HKCU + Uninstaller)،
  بعد از نصب (`مارکر .nexus-serve` یا آرگومان `serve`) = سرور محلی 127.0.0.1 با کل وب‌اپ تعبیه‌شده.
- **APK**: WebView سبک اختصاصی — smali دست‌نویس + AXML/ARSC با پایتون + امضای v1 (SHA256withRSA،
  targetSdk 29). کلید امضا: `build-apk/signing-key.pem` — برای نسخه‌های بعدی نگه دارید تا به‌روزرسانی ممکن باشد.
