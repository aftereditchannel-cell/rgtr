# NEXUS HQ — Native Core v2.0
### بازنویسی کامل Native در پوشه‌ی جدید (`native-app/`) — صفر وب در هر دو پلتفرم

| فایل | حجم | توضیح |
|---|---|---|
| `NEXUS-HQ-NativeCore-Setup.exe` | ۱.۳ MB | 🪟 نصب‌کننده‌ی **دو-معماریه** — خودش x64/x86 سیستم را تشخیص می‌دهد، شورتکات + Uninstaller |
| `NEXUS-HQ-NativeCore.exe` | ۱.۰ MB | 🪟 نسخه‌ی x64 مستقل (C++ خالص + Win32/GDI) |
| `NEXUS-HQ-NativeCore-x86.exe` | ۱.۰ MB | 🪟 نسخه‌ی x86 برای ویندوزهای ۳۲بیتی |
| `NEXUS-HQ-NativeCore-1.0.0-android.apk` | ۲۸۰ KB | 📱 Java خالص — صفر مجوز، صفر WebView |

## ماژول‌های ویندوز (۸ ماژول)
داشبورد (کارت‌ها + نمودار ستونی) · تسک‌ها (اولویت/انجام) · پروژه‌ها (چرخش وضعیت) ·
مشتریان (نام+موبایل) · یادداشت‌ها (سنجاق) · مالی (درآمد/هزینه/مانده) ·
**تقویم شمسی کامل** (الگوریتم جلالی پورت‌شده از سورس اصلی) · درباره + راهنما

فونت وزیرمتن (۴ وزن، ~۵۰۰KB) داخل هر دو EXE تعبیه شده. داده‌ها در `%LOCALAPPDATA%\NEXUS-HQ-NativeCore`.

## ماژول‌های اندروید
تسک‌ها · یادداشت‌ها · مالی · درباره — Java خالص با فونت وزیرمتن از assets.

## درباره‌ی حجم — شفاف و صادقانه
اپ‌های ۱۰۰-۲۰۰ مگابایتی (تلگرام ۷۰MB، Teams ۲۰۰MB) این حجم را از **باندل کردن فریم‌ورک**
می‌گیرند (Qt / Electron / .NET). کانال دانلود همه‌ی این فریم‌ورک‌ها پشت فایروال این محیط
بسته است و Electron خودش ممنوع (وب). اپ Native واقعی بدون فریم‌ورک، طبیعتاً ۱-۲MB است —
مثل Notepad ویندوز (۲۰۰KB) یا Calculator (۹۰۰KB). حجم این اپ = کد واقعی + فونت‌های واقعی،
هیچ فایل پفی داخلش نیست.
